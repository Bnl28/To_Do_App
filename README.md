# To-Do App

A clean, responsive React To-Do application built with React Hooks (`useState`, `useReducer`, `useRef`) by **Binal Nasit**.

- **Repository:** https://github.com/Bnl28/To_Do_App

## Features

- Add new tasks with instant validation
- Inline task editing with keyboard shortcut support (`Escape` to cancel, `Enter` to save)
- Mark tasks as done with smooth exit animations
- Live remaining task counter and empty-state guidance
- Responsive glassmorphism card layout with reduced-motion support

## Tech Stack

- React 18 (`useState`, `useReducer`, `useRef`)
- CSS3 (custom properties, keyframe animations, responsive media queries)
- Create React App (`react-scripts`)

## Getting Started

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
```
